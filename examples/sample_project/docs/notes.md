# Background notes

This file is deliberately less important than the README and source code in the
prototype's fixed ordering. A small budget should omit this whole file while
keeping the two smaller files intact. The JSON report identifies the omission.

This sample demonstrates selection, not semantic summarization. An assistant
does not receive the contents of an omitted file, and the user should inspect
the report to decide whether a larger budget is needed. No conclusion about
answer quality or billing savings can be drawn from this demonstration alone.
